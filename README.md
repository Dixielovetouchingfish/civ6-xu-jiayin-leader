# civ6-xu-jiayin-leader
Civilization VI Gathering Storm leader mod featuring Xu Jiayin.
# 许家印：高歌猛进

为《Sid Meier's Civilization VI》风云变幻资料片制作的中华文明自定义领袖模组。

**Xu Jiayin – Advance at Full Speed**  
A custom leader mod for China in Civilization VI: Gathering Storm.

> 本模组属于非官方、非商业的游戏模组与戏仿创作。游戏机制经过艺术化、虚构化处理，不应视为对现实人物、企业或历史事件的事实陈述。

---

## 主要内容

许家印作为中华文明的可选领袖，拥有三阶段领袖能力 **“高歌猛进”**。

### 风光无限

远古和古典时代侧重高速扩张：

- 人口增长速度提高
- 城市中心提供额外食物和生产力
- 城市获得额外住房
- 人口转化为额外科技值
- 建筑、移民和专业区域建造速度提高
- 首个专业区域获得更高生产加成
- 对蛮族获得有限战斗优势
- 小型新城获得临时忠诚度保护
- 每座城市首次建成专业区域时获得一次金币回款

### 高杠杆扩张

中古和文艺复兴时代：

- 保留较弱的区域与建筑生产加成
- 提高大商人和大工程师点数
- 拥有较多专业区域的城市开始承担金币成本

### 债务重组

工业时代及以后：

- 前期生产和伟人点数加成失效
- 高度开发城市承担金币和宜居度压力
- 首都获得一定金币补偿
- 需要利用专属建筑和后期内容完成恢复

---

## 专属内容

### 恒驰汽车

替代现代装甲：

- 与现代装甲拥有相同基础战斗力
- 移动力更高
- 生产成本更低
- 在己方领土内获得额外战斗力

### 保交楼工程

城市中心专属建筑：

- 提供住房
- 提供宜居度
- 提供金币
- 用于缓解后期城市压力

### 恒大御湖天下大门

每个帝国最多建造一座的国家奇观式建筑：

- 提供住房、宜居度和金币
- 建成后获得一次性金币
- 在有限回合内提高帝国生产效率
- 提高保交楼工程的建造速度

## 安装方法

### 方法一：Steam创意工坊

1. 在Steam创意工坊订阅本模组。
2. 等待Steam完成下载。
3. 启动《文明6》。
4. 打开“额外内容 → 模组”。
5. 启用本模组和风云变幻资料片。
6. 创建游戏并选择中华文明的许家印。

### 方法二：GitHub手动安装

1. 在本仓库右侧进入 `Releases`。
2. 下载最新版本的ZIP安装包。
3. 解压后，将模组文件夹放入：
